## 3.2 User Stories

### Segmentos objetivo
- Usuarios en zonas rurales o con baja conectividad
- Usuarios en actividades outdoor (senderismo, camping, expediciones)
- Equipos de emergencia y contingencia

### Epics

| Epic ID | Título | Descripción |
|--------|--------|-------------|
| EP-01 | Comunicación offline sin internet | Como usuario en zonas rurales o sin conectividad, quiero enviar y recibir mensajes sin acceso a internet, para poder comunicarme en cualquier entorno. |
| EP-02 | Comunicación en emergencias | Como personal de emergencia, quiero comunicarme de forma confiable sin depender de redes tradicionales, para coordinar acciones en situaciones críticas. |
| EP-03 | Comunicación outdoor de largo alcance | Como usuario en actividades outdoor, quiero comunicarme a largas distancias mediante tecnología LoRa, para mantener contacto en expediciones o zonas remotas. |
| EP-04 | Conexión app–dispositivo vía Bluetooth | Como usuario, quiero que mi celular se conecte por Bluetooth a un dispositivo LoRa, para poder enviar mensajes desde la app sin necesidad de internet. |
| EP-05 | Red LoRa y retransmisión multi-hop | Como developer del sistema, quiero implementar la comunicación entre nodos LoRa con retransmisión (multi-hop), para ampliar el alcance de la red entre dispositivos. |
| EP-06 | Mensajería segura y confiable | Como usuario, quiero que mis mensajes estén cifrados y lleguen correctamente, para asegurar privacidad y confiabilidad en la comunicación. |
| EP-07 | Modo offline con almacenamiento local | Como usuario con conectividad intermitente, quiero que los mensajes se almacenen localmente y se envíen cuando haya conexión LoRa disponible, para no perder información. |
| EP-08 | Interfaz móvil simple e intuitiva | Como usuario con poca experiencia tecnológica, quiero una aplicación fácil de usar, para poder comunicarme sin complicaciones técnicas. |
| EP-09 | Visualización del estado de conexión | Como usuario, quiero ver el estado de conexión Bluetooth y LoRa, para saber si puedo enviar mensajes correctamente. |
| EP-10 | Optimización energética | Como usuario en campo o emergencia, quiero que el sistema consuma poca batería, para poder usarlo durante largos periodos sin recarga. |
| EP-11 | Arquitectura escalable del sistema | Como developer del sistema, quiero diseñar una arquitectura robusta basada en nodos LoRa y comunicación Bluetooth, para soportar múltiples usuarios sin degradar el rendimiento. |
| EP-12 | Configuración sencilla de dispositivos | Como usuario, quiero configurar fácilmente el dispositivo LoRa desde mi celular, para empezar a usar el sistema sin conocimientos técnicos avanzados. |
| EP-13 | Landing Page informativa | Como visitante, quiero acceder a una landing page informativa, para conocer la propuesta de valor, funcionamiento y beneficios de OffGrid Messenger. |
| EP-14 | Gestión de comunicación Bluetooth | Como developer del sistema, quiero implementar la gestión de conexión Bluetooth entre la app móvil y el dispositivo LoRa, para asegurar una comunicación estable y eficiente. |
| EP-15 | Manejo de errores y reconexión | Como developer del sistema, quiero implementar manejo de errores y reconexión automática, para garantizar que el sistema siga funcionando ante fallos de conexión o pérdida de señal. |
